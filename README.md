# Ganesh Ramasane | GitHub Profile Website

A dark red/black animated personal GitHub profile website for **Ganesh Ramasane**.

## Run locally

Open `index.html` in your browser, or use VS Code with the Live Server extension.

## Structure

- `index.html` - main page
- `css/style.css` - styling and animations
- `js/script.js` - typing effect, particles, reveal animations and interactions
- `assets/ganesh-symbol.svg` - uploaded Ganesh symbol artwork
